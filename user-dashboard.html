خطوات التفعيل الفوري

1. ابحث في تليجرام عن بوت:
@BotFather واصنع بوت جديد بكلمة /newbot.
2. انسخ الـ HTTP API Token الذي سيعطيه لك وضعه في الخانة الأولى.
3. ابحث عن بوت:
@userinfobot وأرسل له رسالة، سيعطيك الـ ID الخاص بك. ضعه في الخانة الثانية.

الآن ستصلك الطلبات خفية وفورياً بمجرد ضغط الزبون على شراء!
